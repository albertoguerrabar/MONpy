# Acrolein

From the repository root, run:

```bash
python main.py --config examples/acrolein/monpy.toml
```

This example uses the two fragments A (ATOM 1–4) and B (ATOM 5–8).
The run writes two heatmaps, a text report and a CSV under `examples/acrolein/results/`.

| State | Energy (eV) | CT fraction |
| --- | ---: | ---: |
| S1 | 2.2962 | 0.081304 |
| S2 | 4.3202 | 0.060786 |
